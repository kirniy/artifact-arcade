# MEAN GIRLS typography

Anton.ttf is copied unchanged from the approved motion source:
`VIDEOS/Mean Girls 2/production/complete-package/vertical/assets/Anton.ttf`.
Used for Latin brand/time; Impact remains an AE-only source font and is not distributed.

Unbounded.ttf is the full original Google Fonts variable font (including Cyrillic,
Latin and numbers), rather than the motion project's split WOFF2 language subsets.
Source: https://github.com/google/fonts/blob/main/ofl/unbounded/Unbounded%5Bwght%5D.ttf
Used for the Russian footer; no font conversion is needed on the Pi.

Both families use the accompanying SIL Open Font License files. The runtime
requires only its existing Pillow/FreeType support; fonttools is a local QA tool.
