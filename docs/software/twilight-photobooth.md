# TWILIGHT photobooth

TWILIGHT uses Romance Club-inspired drawn 2D guests in a luminous misty evergreen forest. Identity, expression, hairstyle, gender, age, group count, body build and poses take precedence over style. Guests must never become Twilight cast members. Reference order is source photo, approved oval emblem, campaign forest wallpaper, then identity face crops. Both theme reference files have independent SHA-256 pins; missing or altered assets refuse generation. The wallpaper's sideways lettering is excluded from generated artwork; one supplied oval emblem is integrated above the guests. The source wallpaper remains unchanged. The forest is rendered substantially brighter with pale sage, silver blue and pearl mist, retaining atmospheric trees rather than a white studio background. The existing verified footer and thermal receipt path are reused. One generation serves display, print and sharing; no extra AI call is added to guest flow.

Idle source is the NEW final five-object fan video `/Users/kirniy/dev/VIDEOS/TWILIGHT/masters/TWILIGHT-FAN-REVIEW-720p.mp4` (emblem, apple, moon, wolf, chess queen), not the old emblem-only intermediate. Clop downsized a separate copy to silent H.264/yuv420p 128×128, retaining all 60 seconds at 30 fps. The existing cached-frame player loops it at its native speed. Originals are preserved. Assets live in `assets/images/twilight-*` and `assets/idle/twilight/video/twilight-fans.mp4`.

Activation: `sudo -n bash scripts/activate-twilight-photobooth.sh --restart`. This validates both image pins, enums/menu wiring, video dimensions/codec/FPS/duration and full video decode before writing an atomic private `.env` update. The previous `.env` is backed up once. The default/menu theme becomes `twilight`; actual Tickets Cloud «ВСЕ СВОИ» nights still override it from 23:00 through 07:00 Moscow. No weekday guessing, cached events persist across power cycles and poll asynchronously. The installed provider/model, camera and unrelated runtime settings remain unchanged. Restart is idle-gated and deferred if a guest is active.

Deploy only after checking a clean tracked runtime, updater, fresh idle and a recoverable Git checkpoint. Restore the updater timer after deployment. Verify active service, selector agreement, canonical references, video playback, live image generation and thermal preview. An ESC/POS bitmap is not proof of physical paper quality; disconnected USB printing must be reported. Roll back at idle by reverting the release commit and restoring the private pre-TWILIGHT `.env`, then restarting the service.
