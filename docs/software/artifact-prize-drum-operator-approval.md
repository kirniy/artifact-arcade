Лимиты — верхние границы, а не обещание количества. Когда приз недоступен, backend атомарно нормализует выбор только по оставшимся одобренным призам. Нулевой вес и выключенный флаг исключают оба депозита из выдачи, но не из визуального зацикленного барабана.

## Предлагаемый точный текст условий

### `MERCHFREE`

> Один предмет из выделенного ассортимента мерча VNVNC — выбор сотрудника, пока есть в наличии. Сохрани чек и покажи QR сотруднику на стойке напротив гардероба до 07:00 текущей клубной ночи.

### `SHOTFR`

> Один сет из 4 фирменных шотов VNVNC. Состав определяет бар.

### `SHOT1FREE`

> Один бесплатный шот. Состав определяет бар.

### Напитки

Чек требуется сохранить. Для клубной ночи пятницы он направляет в бар **«Малая Виновница»**, для клубной ночи субботы — в бар **«Ангар»**. Погашение возможно до 07:00 этой клубной ночи.

### Остальные условия

- `COCKTL`: один бесплатный коктейль; чек направляет в правильный бар по клубной ночи.
- `DEP1K`, `DEP2K`: только визуальные сектора, выдача выключена.
- `TIX1FREE`: один человек, один проход, одна из двух явно напечатанных следующих полных клубных ночей — пятница или суббота; сейчас никуда подходить не нужно; первое погашение на входе закрывает QR.
